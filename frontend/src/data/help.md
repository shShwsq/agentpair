# AgentPair 使用帮助

AgentPair 是一个**双智能体协作系统**:用户描述任务后,两个智能体分工协作完成。

## 核心概念

### user_agent(评估智能体)

负责**澄清意图**和**评估结果**:

- 任务开始时,若你的描述不够具体,它会通过弹窗向你提问
- react_agent 提交结果后,它对照场景判据评估是否完整
- 若发现未覆盖项,它会打断 react_agent 让其补充

### react_agent(执行智能体)

负责**调用工具执行任务**:

- 内置 react_agent:直接用上方选择的 LLM 模型
- 外部 CLI agent:已配置且启用的外部 CLI(如 codex / qoder),在提交任务页可切换

两者通过**检查点评估**衔接:react_agent 每完成一轮,user_agent 评估一次,决定继续、追问还是完成。

## 页面导览

### 首页 `/`

欢迎落地页。点"提交新任务"进入任务提交页。左上角按钮可展开历史任务侧栏。

### 提交任务 `/tasks/new`

1. **选择场景**:场景提供预设 prompt 模板,选择后自动填入输入框;也可自由输入覆盖
2. **选择 user_agent 模型**:用于结果评估。若列表为空,先到「模型设置」配置 LLM 凭据
3. **选择 react_agent 执行器**:内置 react_agent 直接用上面的模型;若已配置外部 CLI 可在此切换
4. **填写任务描述**:尽量具体——目标、范围、约束、期望产物格式
5. **填写仓库地址与分支**:react_agent 会克隆该仓库到沙盒中执行
6. **点发送按钮**:后端立即返回 task_id 并跳转到任务详情页观看实时进度

### 任务详情 `/tasks/:id`

实时观看任务执行:

- **结果清单**:任务产出的结果按严重程度分组展示
- **协作对话流**:user_agent 与 react_agent 的对话过程,包含思考、工具调用、检查点评估
- **暂停 / 恢复**:运行中可随时暂停,补充信息后恢复执行;暂停期间可向智能体追加指令
- **历史任务切换**:左上角按钮展开侧栏,在多个任务之间快速切换

### 模型设置 `/models`

配置 LLM 凭据(API Key、Base URL、模型名)。支持多个凭据,提交任务时选用。

### CLI 设置 `/cli`

配置外部 CLI 凭据(如 codex / qoder 的 API Key)。配置并启用后,在提交任务页可切换执行器。

### 协作策略 `/agent-policy`

调整 user_agent 的评估行为:

- **评估频率**:每轮都评估 / 仅在 react_agent 完成时评估
- **打断权限**:是否允许 user_agent 打断 react_agent 追问
- **验证权限**:是否启用 verifier_agent 做动态验证

### 记忆管理 `/memory`

编辑**用户偏好**(Markdown 自由文本),注入 user_agent 的系统提示词,影响评判标准与 checklist 生成。

### 账号设置 `/settings`

(由顶栏齿轮按钮进入,不在主导航)

- 修改密码
- GitHub / Gitee 账号绑定
- 登出设备管理

## 快捷操作

### 任务详情页键盘快捷键

- `Enter` 在输入框中发送补充指令
- `Shift + Enter` 换行

### 新手引导

首次进入首页 / 提交任务页 / 任务详情页时会自动弹出新手指引气泡。可点击"跳过引导"关闭,完成后不再自动弹出。

> 若想重新查看新手引导:目前未提供入口。如需重看,清浏览器 localStorage 中 `agentpair:onboarding:*` 相关 key 即可。

## 常见问题

### 提交任务后没反应?

- 检查浏览器控制台是否有 SSE 连接错误
- 确认模型凭据有效(API Key 未过期)
- 仓库地址是否可访问(私有仓库需先绑定 GitHub / Gitee)

### react_agent 报错"模型未配置"?

到「模型设置」配置至少一个 LLM 凭据,提交任务时选择该模型。

### user_agent 一直追问?

它的追问是为了澄清意图,确保任务完整。如实回答即可。若问题与任务无关,可在回答中说明。

### 任务被暂停了?

- 可能是 user_agent 主动打断(发现需要用户澄清)
- 也可能是手动点了暂停按钮
- 在暂停状态下输入补充信息后点"恢复"即可继续

### 想更换执行器但下拉框没有选项?

到「CLI 设置」配置外部 CLI 凭据并启用,回到提交任务页即可看到新选项。
